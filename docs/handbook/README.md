# Handbook

## Purpose

Handbookは、複数のResearch Question（RQ）から得られた知識を
体系化し、再利用可能な形で整理する場所です。

HandbookはResearch Questionのコピーではありません。

RQで得られた知見を横断的に整理し、
実務で活用できる知識体系として管理します。

## Relationship

Microsoft Official Information

↓

Evidence

↓

Research Question (GitHub Issue)

↓

Handbook

↓

Business Application

↓

Publication

## Structure

各Handbookはテーマ単位で作成します。

例

- Copilot
- Knowledge Engineering
- Prompt Engineering
- Microsoft Graph
- AI Agents

## Writing Rules

- RQをコピーしない
- 複数のRQを統合する
- 実務で再利用できる形で整理する
- 必要に応じて図表を追加する
