# Handbook

Version: 1.0

Status: Approved

---

# 1. 目的

Handbook は、Research Lab で得られた知見を体系化し、再利用可能な知識として整理・蓄積するためのドキュメントである。

Handbook は、Research Question（RQ）のコピーではない。

Research Question、Evidence、Verification および LAB を通じて得られた知見を横断的に整理し、実務で再利用可能な知識体系として管理する。

---

# 2. 知識体系

Handbook は、Research Lab における研究成果を次の流れで体系化する。

```text
Research Question
        │
        ▼
Evidence
        │
        ▼
Verification
        │
        ▼
LAB
        │
        ▼
Handbook
        │
        ▼
Business Application
        │
        ▼
Publication
```

Handbook は、研究成果を実務へ適用し、社内外へ発信するための知識ベースとして位置付ける。

---

# 3. 構成

各 Handbook は、テーマ単位で作成する。

必要に応じて、複数の Research Question および Evidence を統合して構成する。

例

- Microsoft 365 Copilot
- Knowledge Engineering
- Prompt Engineering
- Microsoft Graph
- AI Agents

---

# 4. 記述ルール

- Research Question をコピーしない。
- 複数の Research Question を統合する。
- エビデンスに基づいて知見を整理する。
- 実務で再利用できる形で記述する。
- 必要に応じて図表を追加する。
- Handbook は継続的に更新する。
