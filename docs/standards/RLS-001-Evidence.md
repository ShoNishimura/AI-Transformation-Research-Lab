# RLS-001 エビデンス標準

Version: 1.0

Status: Approved

---

## 1. 目的

Research Lab におけるエビデンスの収集、評価および管理方法を標準化し、研究結果の再現性および信頼性を確保する。

---

## 2. 適用範囲

本標準は、Research Lab リポジトリで管理するすべてのエビデンスに適用する。

対象例

- Microsoft Learn
- Microsoft Support
- Microsoft Docs
- Microsoft Tech Community
- Microsoft 365 Blog
- GitHub
- 学術論文
- 実機検証結果
- コミュニティ資料

---

## 3. エビデンスの定義

エビデンス（Evidence）とは、Research Question（RQ）の検証を支える客観的な根拠である。

エビデンスは E-XXX の管理IDで一意に管理する。

---

## 4. エビデンスカード

エビデンスは、Research Lab が定める Evidence Card Template を使用して記録する。

記載項目および書式は、テンプレートに従う。

---

## 5. 信頼性評価

エビデンスは、以下の基準で信頼性を評価する。

| 評価 | 基準 |
|------|------|
| A | Microsoft 公式、国際標準、査読論文 |
| B | 専門企業、著名コミュニティ、技術書 |
| C | 個人ブログ、SNS、未検証情報 |

---

## 6. 運用ルール

- エビデンスは一意の管理IDで管理する。
- 同一資料は重複登録しない。
- 可能な限り一次情報を参照する。
- URLおよび取得日（YYYY-MM-DD、日本時間）を記録する。
- RQへの影響を必ず記録する。
- 必要に応じて関連する Research Question（RQ）および Evidence を記録する。

---

## 7. テンプレート

エビデンスは、Research Lab が定めるテンプレートを使用して記録する。

使用するテンプレート

- `docs/templates/Evidence-Card-Template.md`
