# AI Transformation Handbook

社内ナレッジを活用した、信頼できる業務AIの実装・評価・展開について研究し、再利用可能な知識資産として整理するプロジェクトです。

## Mission

公式情報、実機検証、実務適用を通じて、信頼できる業務AIの実現方法を体系化し、組織と社会へ還元します。

## Research Areas

- Microsoft 365 Copilot
- AI Agents
- Knowledge Engineering
- AI Quality Evaluation
- SharePoint Information Architecture
- Retrieval-Augmented Generation
- AI Governance
- EV-related business use cases

## Research Process

1. Research Questionを設定する
2. 公式情報を確認する
3. 仮説を立てる
4. 実機で検証する
5. 結果を評価する
6. 実務へ適用する
7. 公開可能な形へ一般化する

## Repository Structure

- `research/`：Research Questionと検証結果
- `templates/`：評価表・ログ・チェックリスト
- `docs/`：公開可能な知識・ガイド
- `samples/`：サンプルコード・架空データ

## Publication Policy

所属組織、顧客、実案件、個人、内部システムを特定できる情報は公開しません。

実務で得た知見は、一般化し、架空データまたは公開データで再現した上で公開します。
